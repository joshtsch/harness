# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read ADRs under `docs/adr/` that touch the area being explored.

Use the vocabulary defined in `CONTEXT.md`. If a new domain concept is introduced, update the glossary through the domain-modeling workflow. Surface conflicts with existing ADRs instead of silently overriding them.
